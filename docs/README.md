# Base de conhecimento — Solution Delivery

Fonte original: [guia integrado](../diversos/solution-delivery-codex-completo.md). Os protótipos extraídos estão em `referencias/` e contêm dados ilustrativos independentes.

Ordem de leitura: produto → regras → arquitetura → dados e API → precificação → design → operação → validação. As decisões do usuário prevalecem sobre exemplos dos protótipos.

| [Precificação](precificacao.md) | Métodos, acréscimos e provedores           |

[App do entregador](app-entregador.md) descreve Expo, autenticação móvel, configuração e builds Android/iOS.

Esta base não é um recurso de IA em tempo de execução. É documentação técnica e de produto versionada junto ao código.
